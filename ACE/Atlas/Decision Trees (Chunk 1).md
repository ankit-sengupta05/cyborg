It is a basic machine learning algorithm and provides a wide variety of use cases. It is a dynamic learning algorithm that can produce a regression tree as well as a classification tree depending upon the dependent variable. CART can be applied to both regression and classification problems Steps in Classification and Regression Tree: The algorithm works repeatedly in three steps: Find each feature’s best split. For each feature with K different values there exist K-1 possible splits. Find the split, which maximizes the splitting criterion. The resulting set of splits contains the best splits (one for each feature). Find the node’s best split. Among the best splits from Step, I find the one, which maximizes the splitting criterion. Split the node using the best node split from Step ii and repeat from Step I until the stopping criterion is satisfied Example CART - By using Gini index Gini index can be calculated using the below formula: CART - By using Gini index Dr. Selva Kumar S (SCOPE) Outlook Outlook is a nominal feature.
