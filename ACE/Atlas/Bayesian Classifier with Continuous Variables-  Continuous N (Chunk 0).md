Bayesian Classifier with Continuous Variables: Continuous NB Naïve Bayes (standard) and Naïve Bayes with continuous variables mainly differ in the type of data they handle and how probabilities are computed. Naïve Bayes with Continuous Variables (Gaussian Naïve Bayes) This version handles numerical (continuous) data. 👉 Examples: Height (170 cm, 180 cm) Salary (₹50,000) Temperature (36.5°C) Since we cannot count exact values, we assume the data follows a normal (Gaussian) distribution. 🔹 Simple Intuition Standard NB → “How many times did this occur?” Continuous NB → “How likely is this value based on distribution?” 🔹 Quick Example Email classification → use standard Naïve Bayes Predicting if a person is healthy based on blood pressure, sugar level → use Gaussian Naïve Bayes
