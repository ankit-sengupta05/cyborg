Problem1.Example Relation. Find Highest Normal form Suppose we have a relation: R(A, B, C, D)with functional dependencies (FDs): A → B B → C A → D Step 1: Find Candidate Keys From FD (1) and (2): A → B → C ⇒ A → BC From FD (3): A → D So A → B, C, D ⇒ A → BCD Therefore A is the candidate key. Step 2: Check Normal Forms A → B B → C A → D 1NF Assume all attributes are atomic ⇒ R is in 1NF. 2NF requires no partial dependency. Candidate key = A (single attribute). No partial dependency possible ⇒ R is in 2NF. 3NF Rule: For every FD X → Y, either (a) X is a superkey, OR (b) Y is a prime attribute. Check each FD: A → B ✅ (A is a key) B → C ❌ (B is not a key, and C is not prime) A → D ✅ (A is a key) So violation at B → C ⇒ R is not in 3NF. Therefore Highest normal 2NF. Find Highest Normal form R(A, B, C, D) Functional Dependencies F = {A B → C, B → D, D → A} 1.Find Candidate Keys Start with attribute closure: B⁺ = {B, D, A, C} ✅ B⁺ = {A,B,C,D} So B is a candidate key. 2.Key & Non-Key Attributes Key attributes: B Non-key attributes: A, C, D Normal Form Check 1NF Assume all attributes are atomic ⇒ ✅ 1NF 2NF Only candidate key = B (single attribute) ⇒ no partial dependency ⇒ ✅ 2NF 3NF Rule: for every FD X → Y, either (a) X is a superkey OR (b) each attribute of Y is prime. Prime = ‘attribute that belongs to at least one candidate key of the relation.’ Check each FD: Violations: AB → C and D → A ⇒ ❌ Not in 3NF BCNF Even stricter: every determinant must be a superkey. Already fails 3NF, so ❌ Not in BCNF. 4️Decomposition to BCNF Decompose on AB → C: R1(A,B,C) R2(B,D,A) (but A appears twice; simplify to R2(B,D,A) which is effectively R2(B,D,A)) Then handle D → A inside R2: Split R2 into - R21(D,A) R22(B,D) All resulting relations are in BCNF. CASE 3:LOSSLESS BUT NOT DEPENPENCY PRESERVING DECOMPOSITION EXAMPLE Problem8. - FIND THE HIGHEST NORMAL FORM Relation:R(A, B, C, D, E, F) Functional Dependencies: AB → C C → D D → E E → F F → B Step 1: Find Candidate Key Check (A,B)⁺ Start: {A, B} Using AB → C → {A, B, C} Using C → D → {A, B, C, D} Using D → E → {A, B, C, D, E} Using E → F → {A, B, C, D, E, F} Thus (AB)⁺ = ABCDEF Therefore: Candidate Key = AB Step 2: Prime and Non-Prime Attributes Prime attributes: A, B Non-prime attributes: C, D, E, F Step 3: Check 1NF A relation is in 1NF if attributes contain atomic values. Assume atomic attributes. ✔ Relation is in 1NF Step 4: Check 2NF Rule: No partial dependency. Candidate key = AB Check FDs. AB → C ✔ (full dependency) Other FDs depend on non-key attributes, not part of the key. ✔ No partial dependency Therefore ✔ Relation is in 2NF Step 5: Check 3NF Rule: For FD X → Y X must be super key, OR Y must be prime attribute Check each FD AB → C AB is candidate key ✔ OK C → D C not super key D not prime ❌ violates 3NF D → E D not super key ❌ violates 3NF E → F E not super key ❌ violates 3NF F → B F not super key B is prime ✔ allowed in 3NF Highest Normal Form 1NF ✔ 2NF ✔ 3NF ❌ ⭐ Highest Normal Form = 2NF Step 6: Decompose to BCNF First violation: C → D Create relation: R1(C, D) Remaining relation: R2(A, B, C, E, F) Check R2 FDs: AB → C E → F F → B Candidate key still AB Violation: E → F Create relation R3(E, F) Remaining relation R4(A, B, C, E) Check R4 FDs: AB → C F → B (removed because F not present) Candidate key = AB No violation. Final BCNF Decomposition R1(C, D) R3(E, F) R4(A, B, C, E) Step 7: Verify BCNF R1(C, D) C → D C is key ✔ BCNF R3(E, F) E → F E is key ✔ BCNF R4(A, B, C, E) AB → C AB is key ✔ BCNF Problem 9. - FIND THE HIGHEST NORMAL FORM Functional Dependencies (FDs) AB → C C → A B → D D → E E → F Step 1: Find Candidate Keys Closure of AB Start: AB⁺ = {A, B} Using AB → C → {A, B, C} Using B → D → {A, B, C, D} Using D → E → {A, B, C, D, E} Using E → F → {A, B, C, D, E, F} Thus AB⁺ = ABCDEF So AB is a candidate key Check BC Start: BC⁺ = {B, C} Using C → A → {B, C, A} Using B → D → {B, C, A, D} Using D → E → {B, C, A, D, E} Using E → F → {B, C, A, D, E, F} Thus BC⁺ = ABCDEF So BC is also a candidate key Step 2: Prime and Non-Prime Attributes Prime attributes (part of keys) A, B, C Non-prime attributes D, E, F Step 3: Check 1NF All attributes contain atomic values. ✔ Relation is in 1NF Step 4: Check 2NF Check partial dependencies. Example: B → D B is part of candidate key AB D is non-prime ❌ Partial dependency exists So relation is not in 2NF. Problem10. - FIND THE HIGHEST NORMAL FORM FDs for a pure 3NF but not BCNF case Relation: R(A, B, C) FDs:AB → C, C → A Candidate Keys AB⁺ = ABC → key BC⁺ = BCA → key Candidate keys = AB, BC Prime attributes = A, B, C Check 3NF AB → C AB is super key ✔ C → A C not super key A is prime ✔ allowed in 3NF Thus ✔ Relation is in 3NF Check BCNF For BCNF: determinant must be super key. For C → A C is not a super key ❌ Violates BCNF BCNF Decomposition Decompose using C → A R1(C, A) R2(B, C) Both relations satisfy BCNF. PRACTICE PROBLEMS 1.
