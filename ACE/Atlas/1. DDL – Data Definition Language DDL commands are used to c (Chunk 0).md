1. DDL – Data Definition Language DDL commands are used to create or change the structure of database objects like tables. Commands: 1. CREATE Used to create a new table or database object. Example: CREATE TABLE Student ( ID INT, Name VARCHAR(50), Age INT ); 2. ALTER Used to modify an existing table structure (add, modify, delete columns). Example: ALTER TABLE Student ADD Address VARCHAR(100); 3. DESCRIBE (DESC) Used to view the structure of a table. Example: DESC Student; 4. DROP Used to delete a table permanently from the database. Example: DROP TABLE Student; 5. TRUNCATE Used to delete all records from a table but keeps the table structure. Example: TRUNCATE TABLE Student; 6. RENAME Used to change the name of a table. Example: RENAME Student TO Student_Details; 2. DML – Data Manipulation Language DML commands are used to manipulate the data inside the table. Commands: 1. INSERT Used to add new records into a table. Example: INSERT INTO Student (ID, Name) VALUES (1, 'Ravi'); 2. UPDATE Used to modify existing data in a table. Example: UPDATE Student SET Age = 21 WHERE ID = 1; 3. SELECT Used to retrieve data from a table. Example: SELECT * FROM Student; 4. DELETE Used to remove records from a table. Example: DELETE FROM Student WHERE ID = 1; 3. DCL – Data Control Language DCL commands are used to control access and permissions in a database. Commands: 1. GRANT Used to give privileges to users. Example: GRANT SELECT, INSERT ON Student TO user1; 2. REVOKE Used to remove privileges from users. Example: CREATE USER USER1 IDENTIFIED BY tiger; GRANT SELECT ON Student TO USER1; REVOKE INSERT ON Student FROM user1; 4. TCL – Transaction Control Language TCL commands are used to manage database transactions. Commands: 1. COMMIT Used to save all changes permanently in the database. Example: COMMIT; 2. ROLLBACK Used to undo changes if something goes wrong. Example: ROLLBACK; 3. SAVEPOINT Used to set a point inside a transaction to rollback later. Example: SAVEPOINT A; 5. DRL – Data Retrieval Language DRL commands are used to retrieve and filter data from tables. Commands: 1. WHERE Used to filter records based on condition. SELECT * FROM Student WHERE Age > 20; 2. DISTINCT Used to remove duplicate values. SELECT DISTINCT Age FROM Student; 3. ORDER BY Used to sort the result in ascending or descending order. SELECT * FROM Student ORDER BY Age DESC; 4. GROUP BY Used to group rows with same values. SELECT Age, COUNT(*) FROM Student GROUP BY Age; 5. HAVING Used to apply condition on grouped data. SELECT Age, COUNT(*) FROM Student GROUP BY Age HAVING COUNT(*) > 1; 6. SQL Aggregate Functions Aggregate functions are used to perform calculations on multiple rows and return a single value. 1. MIN() Returns the smallest value. SELECT MIN(Age) FROM Student; 2. MAX() Returns the largest value. SELECT MAX(Age) FROM Student; 3. COUNT() Returns the number of rows. SELECT COUNT(*) FROM Student; 4. AVG() Returns the average value. SELECT AVG(Age) FROM Student; 5. SUM() Returns the total sum of values. SELECT SUM(Age) FROM Student; 1. Arithmetic Operators Used to perform mathematical calculations in SQL. Operators: + , - , * , / , % + (Addition) – Adds two values SELECT Salary + 1000 FROM Employee; - (Subtraction) – Subtracts one value from another SELECT Salary - 500 FROM Employee; * (Multiplication) – Multiplies values SELECT Salary * 2 FROM Employee; / (Division) – Divides one value by another SELECT Salary / 2 FROM Employee; % (Modulus) – Returns remainder after division SELECT Salary % 2 FROM Employee; 2. Comparison Operators Used to compare two values. Operators: = , > , < , >= , <= , <> = (Equal to) SELECT * FROM Student WHERE Age = 20; > (Greater than) SELECT * FROM Student WHERE Marks > 75; < (Less than) SELECT * FROM Student WHERE Marks < 40; >= (Greater than or equal to) SELECT * FROM Student WHERE Marks >= 60; <= (Less than or equal to) SELECT * FROM Student WHERE Marks <= 50; <> (Not equal to) SELECT * FROM Student WHERE Age <> 21; 3. Logical Operators Used to combine multiple conditions. Operators: AND , OR , NOT AND – Both conditions must be true SELECT * FROM Student WHERE Age > 18 AND Marks > 60; OR – At least one condition must be true SELECT * FROM Student WHERE Age > 18 OR Marks > 60; NOT – Reverses the condition SELECT * FROM Student WHERE NOT Age = 20; 4. Special Operators Used for special conditions in SQL queries. BETWEEN – Select values within a range SELECT * FROM Student WHERE Marks BETWEEN 50 AND 80; IN – Matches values in a list SELECT * FROM Student WHERE City IN ('Hyderabad', 'Vijayawada'); LIKE – Searches for a pattern SELECT * FROM Student WHERE Name LIKE 'A%'; EXISTS – Checks if a subquery returns records SELECT * FROM Student WHERE EXISTS (SELECT * FROM Marks WHERE Student.ID = Marks.ID); ANY / ALL – Compare value with subquery results SELECT * FROM Student WHERE Marks > ANY (SELECT Marks FROM Result); 5. Bitwise Operators Used to perform bit-level operations. Operators: & , | , ^ , ~ & (Bitwise AND) SELECT 5 & 3; | (Bitwise OR) SELECT 5 | 3; ^ (Bitwise XOR) SELECT 5 ^ 3; ~ (Bitwise NOT) SELECT ~5; 6. Set Operators Used to combine results of two SELECT queries. UNION – Combines results and removes duplicates SELECT Name FROM Student1 UNION SELECT Name FROM Student2; INTERSECT – Returns common records SELECT Name FROM Student1 INTERSECT SELECT Name FROM Student2; EXCEPT – Returns records from first query not in second SELECT Name FROM Student1 EXCEPT SELECT Name FROM Student2; 1. JOINS Join is used to combine rows from two or more tables based on a related column. Example Tables Student Table Department Table 2. INNER JOIN Returns only matching records from both tables. SQL Command SELECT Student.Name, Department.DeptName FROM Student INNER JOIN Department ON Student.DeptID = Department.DeptID; Output EQUI JOIN Join using equality (=) condition. SQL Command SELECT * FROM Student S, Department D WHERE S.DeptID = D.DeptID; Output NATURAL JOIN Automatically joins columns with the same name. SQL Command SELECT * FROM Student NATURAL JOIN Department; Output 3. OUTER JOIN LEFT JOIN Returns all records from left table and matching from right table. SQL Command SELECT Student.Name, Department.DeptName FROM Student LEFT JOIN Department ON Student.DeptID = Department.DeptID; Output RIGHT JOIN Returns all records from right table and matching from left table. SQL Command SELECT Student.Name, Department.DeptName FROM Student RIGHT JOIN Department ON Student.DeptID = Department.DeptID; Output FULL JOIN Returns all records from both tables. SQL Command SELECT Student.Name, Department.DeptName FROM Student FULL JOIN Department ON Student.DeptID = Department.DeptID; Output 4. CROSS JOIN Returns Cartesian product (all combinations). SQL Command SELECT Student.Name, Department.DeptName FROM Student CROSS JOIN Department; Output (Example) 5. VIEWS A View is a virtual table created from a SQL query. Create View SQL Command CREATE VIEW Student_View AS SELECT Name, DeptID FROM Student; Select From View SQL Command SELECT * FROM Student_View; Output 6. Steps in Query Processing SQL query execution happens in several steps. Parsing SQL query is checked for syntax errors. Translation SQL query is converted into Relational Algebra expression. Optimization Query optimizer finds best execution plan. Execution Database executes the query and returns results. 7. Transforming SQL Query to Relational Algebra SQL Query SELECT Name FROM Student WHERE DeptID = 101; Relational Algebra σ DeptID=101 (Student) π Name (σ DeptID=101 (Student)) Explanation σ (Selection) → filter rows π (Projection) → select columns 8. Heuristic Query Optimization It improves query performance by applying rules. Common Rules Selection First Apply WHERE condition early.
